# Бот подписки «Клуб Единомышленников»

Бот продаёт месячную подписку на закрытый канал через Telegram Stars, с анкетой-прогревом перед оплатой.

## Что делает

1. `/start` → анкета: имя → цель → боль → оффер с ценой (1111 ⭐, зачёркнуто 1999 ⭐)
2. Кнопка «Оформить подписку» → инвойс в звёздах с автопродлением (30 дней)
3. Кнопка «У меня нет звёзд» → ссылка на @suastarsbot для покупки звёзд
4. После оплаты — одноразовая пригласительная ссылка в канал (действует один переход)
5. Если автопродление не прошло (не хватило звёзд) — бот 3 дня подряд напоминает пополнить баланс, затем удаляет из канала
6. `/stats` (только для ADMIN_ID) — статистика: подписчики, доход, ближайшие продления

## Настройка перед запуском

1. Получи токен бота у @BotFather
2. Убедись, что бот добавлен **администратором** в канал `-1002432900064` с правом приглашать пользователей и удалять участников (Invite users via link, Ban users)
3. Узнай свой Telegram ID (например через @userinfobot) — это будет `ADMIN_ID`

## Деплой на Railway

1. Создай новый проект на Railway → Deploy from GitHub repo (или загрузи этот код в свой репозиторий)
2. В Variables добавь:
   - `BOT_TOKEN` — токен бота
   - `ADMIN_ID` — твой Telegram ID
   - `CHANNEL_ID` — `-1002432900064` (уже стоит по умолчанию, можно не менять)
3. Railway автоматически поставит зависимости из `requirements.txt` и запустит `python bot.py`
4. Если Railway не подхватил команду запуска — добавь файл `Procfile` со строкой:
   ```
   worker: python bot.py
   ```

## Важно про Telegram Stars подписки

- Автопродление на стороне Telegram работает автоматически, пока у пользователя хватает звёзд на балансе
- Бот отслеживает срок подписки сам (поле `expires_at` в SQLite) и запускает льготный период, если новая оплата не пришла вовремя
- Если хочешь на 100% синхронизировать логику с реальным поведением автосписаний Telegram — раз в 1-2 недели после запуска стоит сверить `/stats` с реальными участниками канала и при необходимости подправить `GRACE_PERIOD_DAYS` в `config.py`

## Правки текстов

Все тексты анкеты, оффера и напоминаний — в файле `texts.py`. Это черновик, меняй свободно под свой стиль.
